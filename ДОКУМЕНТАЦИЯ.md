# parmenides.academy — техническая документация

Живой документ. Пополняется по мере работы. Дата начала: 24.08.2026.

## 1. Назначение сайта (из ответов Тимура, 24.08.2026)

Сайт — не лендинг, а библиотека-приманка. Цель: сделать курс виральным через материалы со ссылкой на сайт и через материалы на самом сайте, которые копят SEO на русском, английском и французском. Целевое действие посетителя одно: увидеть редкий и умный материал и написать Тимуру в Telegram (@timuratnashev). Рост — в «академию»: упражнения, переводы, комментарии, инфографики, «умная машина Кирилла», вопросы и ответы Дмитрия Бугая (по согласованию). Закрытого контура нет, всё открыто.

Следствия для архитектуры: каждый материал = отдельный URL с полноценным текстом в HTML (не в JS); на каждой странице кнопка «Написать в Telegram»; данные отделены от вёрстки; три языка как три набора страниц с hreflang, а не автоперевод.

Пока деплой — прямой загрузкой zip-архива `dist/` через панель (Workers & Pages → parmenides-academy → Create deployment); GitHub-автодеплой — следующий шаг.
- Домен: **parmenides.academy**, Namecheap (аккаунт Timur75), куплен 24.08.2026, до 24.08.2027, autorenew и WithheldForPrivacy включены. 24.08.2026 nameservers переключены на Cloudflare: piper.ns.cloudflare.com, rick.ns.cloudflare.com (Custom DNS). ## 3. Структура проекта

```
site/
  astro.config.mjs        домен, sitemap, языки (ru по умолчанию без префикса; /en, /fr)
  package.json
  public/                 статические файлы, отдаются как есть
    exercises/*.pdf       раздатки
    img/parmenides_tree.svg
    META_Brain_onepager.pdf
    favicon.svg, robots.txt
  src/
    i18n.ts               тексты шапки/подвала на трёх языках, ссылка на Telegram
    content.config.ts     схема markdown-материалов (title, description, date, lang, section, draft)
    content/articles/ru|en|fr/*.md    материалы академии — ОДИН ФАЙЛ = ОДНА СТРАНИЦА
    data/parmenidesMap.ts             данные карты филиаций (45 узлов), перенесены с Lovable без изменений
    components/polygons_body.html + polygons_style.css   «Три полигона вне Запада», перенесены из HTML-файла
    layouts/Base.astro    общий каркас: шапка, меню, переключатель языка, кнопка Telegram, подвал, hreflang, стили
    pages/
      index.astro         лендинг курса (тексты перенесены с meta-convert-pro.lovable.app)
      map.astro           карта филиаций — рендерится из data/parmenidesMap.ts в обычный HTML (<details>), фильтры и поиск на маленьком скрипте
      polygons.astro      три полигона
      exercises.astro     список раздаток (PDF)
      materials.astro     оглавление библиотеки + автоматический список markdown-материалов
      [...slug].astro     динамическая страница для каждого markdown-файла: content/articles/ru/foo.md → /foo
      en/, fr/            английская и французская версии; index переведён, остальные пока отдают русскую версию
  ДОКУМЕНТАЦИЯ.md         этот файл
  КАК_ДОБАВИТЬ_СТРАНИЦУ.md инструкция для редактора
```

## 5. Дизайн и тон

Бриф Тимура (24.08.2026): аудитория — подросток и взрослый; «дизайн как наши материалы»; убрать дешёвый маркетинг; серьёзная традиция; «клуб и серьёзная работа». Следствие для текстов: без эмодзи, звёздочек, восклицаний и «пробных занятий»; спокойный академический регистр, конкретика вместо обещаний.

Стиль «Кабинетный классицизм» (тот же, что у раздаток и HTML-карты): бумага #fbfaf8, чернила #14161a, акцент винный #7a2230, зелёный #2f6b4f («работает с текстом»), охра #b08d2e («через посредника»). Шрифты: Georgia для текста, Helvetica/Arial для служебного. Переменные объявлены в Base.astro в `:root`; менять цвета — там.
