# Как добавить страницу на сайт

Три действия.

1. Скопируйте файл `src/content/articles/ru/kak-dobavit-stranicu.md` в ту же папку и переименуйте латиницей — это будет адрес страницы. Файл `dva-puti-parmenida.md` станет `parmenides.academy/dva-puti-parmenida`.

2. Откройте файл в любом текстовом редакторе. Заполните шапку между `---`:

```
---
title: Два пути Парменида
description: Одна-две фразы — они показываются в поиске Google и в списке материалов.
date: 2026-09-01
lang: ru
section: commentary      # exercises | translations | commentary | infographics | qa | notes
draft: false             # false — страница публикуется
---
```

Ниже шапки — текст. Заголовки через `##`, курсив `*так*`, жирный `**так**`, цитата — строка, начинающаяся с `>`. Греческий, санскрит, арабский пишутся как есть.

3. Сохраните и отправьте файл Клоду (или положите в папку проекта и скажите «опубликуй»). Через минуту страница появится на сайте и в разделе «Материалы».

Если удобнее писать в Word — присылайте .docx, конвертация на мне.

Английская и французская версии: тот же файл кладётся в `articles/en/` или `articles/fr/` с `lang: en` / `lang: fr`.
